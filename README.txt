SCMW — Lone Wolf
================
An unofficial, fan-made tool for making SCUM mods on Windows.
Not affiliated with, endorsed by, or supported by Gamepires or Steam.

WHAT IT DOES
- Browse SCUM's real items and change their values.
- Build a mod .pak, install it into SCUM, and manage your mods.
- Launch SCUM modded or vanilla.
Your changes are saved per project, so you can work on several mods at once.

REQUIREMENTS
- Windows 64-bit
- SCUM, installed through Steam
- SCUM's unlock key (the app does not include it — see below)

GETTING STARTED
1. Run SCMW-Lone-Wolf.exe.
2. Open Settings. Press "Detect" to find your SCUM folder.
3. Paste your unlock key and press "Test".
4. Create a project, edit some items, then Build and Install into SCUM.

THE UNLOCK KEY
SCUM's files are encrypted. You need the shared unlock key to read them.
In the app, go to Settings > Unlock key and press "Where do I get this?".

SANDBOX AND SERVERS
SCMW — Lone Wolf is made for playing SCUM in Sandbox (local) mode, where your mods load straight away.
On a server, mods only work if the server admin allows them — you can't add a mod to someone else's
server. Server admins can still use this tool to create mods, then deploy them to the server manually
and share them with their players.

NO INSTALL NEEDED
This is portable and self-contained: unzip it anywhere and run the .exe.
To uninstall, just delete the folder.
Windows may warn on the first run (the app is unsigned): More info > Run anyway.
Some antivirus tools flag self-contained apps; the app is open source and safe.

WHERE YOUR WORK LIVES
- Projects, built mods, backups:  Documents\SCMW
- Settings and unlock key:       %APPDATA%\SCMW
Updating is safe: your work is kept outside the app folder.
